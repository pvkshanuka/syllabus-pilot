1. Course Objectives:
Students will learn exploratory data analysis, feature engineering, supervised learning (linear models, trees, ensembles), unsupervised learning (clustering, dimensionality reduction), and model evaluation with ethical AI principles.

2. Course Modules:
- Module 1: Python for Data Science (NumPy, Pandas, Matplotlib)
- Module 2: Exploratory Data Analysis & Feature Engineering
- Module 3: Regression Models (Linear, Ridge, Lasso)
- Module 4: Classification (Logistic Regression, Decision Trees, Random Forests)
- Module 5: Support Vector Machines & Gradient Boosting (XGBoost, LightGBM)
- Module 6: Unsupervised Learning (K-Means, PCA, t-SNE)
- Module 7: Deep Learning Foundations & Neural Networks
- Module 8: Responsible AI, Bias Detection & Model Explainability
